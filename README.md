🐞 BugBuddy — Java Error Explanation Tool

About the Project

BugBuddy is a beginner-friendly Java console application that helps students understand common Java programming errors. 
It explains what an error means, suggests ways to fix it, and provides example code.

Features

- View common Java errors
- Search errors by name or keyword
- Read simple error explanations
- See suggested fixes
- Explore example code
- View search history during the current session

Technologies Used

- Java
- Java Scanner
- Arrays
- ArrayList
- String handling
- Loops and conditional statements

How to Run

1. Install JDK 21 or a compatible Java JDK.

2. Download "BugBuddy.java".

3. Open a terminal in the folder containing the file.

4. Compile the program:
   
   javac BugBuddy.java

5. Run the program:
   
   java BugBuddy

Learning Outcomes

This project demonstrates basic Java programming, searching, collections, user input, and error-handling concepts.

Project Status

Beginner-friendly console application developed as a Java learning project.
